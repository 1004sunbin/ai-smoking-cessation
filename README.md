# 每一根 · 戒烟助手

> 每一根都记下来，但一次复吸不让你从零开始。

一个移动端优先的戒烟 Web 应用，主打 **烟瘾急救**、**复吸后继续陪伴**，以及一个会查看记录、替你准备下一步的 **AI 助手（Agent）**。纯静态页面，无依赖、无数据库，所有记录只保存在用户浏览器中。

## 运行

双击 `index.html` 用浏览器打开即可。首次打开先设定目标（戒烟或减量、每天支数、价格），然后直接开始记录。想先看效果，可以在「设置 → 载入演示数据」载入一份标注为「演示」的模拟数据。

项目介绍页（作品集）：在地址后加 `#about`，或在欢迎卡片 / 设置里点「关于这个项目」。

## 核心流程

| 流程 | 内容 |
| --- | --- |
| 设定目标 | 戒烟或减量；每天支数、每包价格作为基线。减量模式每周目标比基线降低 20% |
| 一键记录 | 「忍住了」一键记录；「抽了一根」记录场景；支持撤销、删除和补记更早的时间 |
| 烟瘾急救 | 选场景和渴求强度 → 推荐动作并计时 → 挺过去 / 还是抽了 → 评价方法是否有帮助 |
| 复吸之后 | 不评判；展示仍然有效的累计进度，针对诱因给出下一步 |
| 每周回顾 | 7 日趋势（基线 / 目标）、急救成功率、对你有效的方法、「下周试试这一件事」并追踪使用情况 |
| 助手 | 说出当下情况，助手查看记录、挑办法，给出急救 / 计划 / 提醒 / 记一笔卡片，点了才执行 |
| 主动提醒 | 「今天的预案」在用户近两周最常抽烟的时段前两小时提示提前准备 |

急救推荐得分 = 场景匹配 + 强度匹配 + 个人效果（基于用户自己的评价），关闭个性化授权后只按场景和强度推荐。

## 隐私

- 记录、打卡、急救评价只存在本机 localStorage，不上传
- 助手默认由 AI 驱动（输入框下方注明），可在设置里一键关闭、改用本地规则；工具在浏览器执行，只发送对话和统计结果
- 危机、急症、用药话题始终在浏览器端用固定回复（12356 / 120 / 12320），不发给 AI
- 设置中可一键清除全部数据；演示数据单独标注，可重置

## AI 助手（Agent）

```
浏览器                                   阿里云函数（Key 在这里）      智谱 GLM
 用户消息 ───────────────────────────────▶ 固定提示词 + 7 个工具定义 ──▶ 决定调用哪些工具
 在本机执行工具（读 localStorage 算统计）◀──────── tool_calls ◀───────┘
 工具结果（只有统计数字）────────────────▶ 转发 ──────────────────────▶ 最终回复
 显示回复 + 卡片，用户点了才执行
```

- 7 个工具：`get_progress`、`find_patterns`、`recommend_methods`（只读）；`offer_sos`、`offer_plan`、`offer_reminder`、`offer_log`（只生成卡片）
- 一条消息最多 4 轮工具调用、最多 2 张卡片；AI 连不上时同一套工具按本地规则执行
- **不需要数据库**：记录只属于一个人、只在一台设备上用；云函数磁盘会随实例回收，存了反而丢。需要账号和跨设备同步时再接托管数据库

- 线上：`js/ai-config.js` 里只写云函数地址，没有密钥；服务端代码和部署步骤见 [server/](server/)
- 云函数只接受本站调用，每位访客每天 20 条（工具往返不重复计数），提示词和工具清单在服务端固定，不保存任何内容
- 本机直连（可选）：复制 `js/config.example.js` 为 `js/config.local.js` 填 Key；该文件已被 `.gitignore` 忽略

## 目录

```
index.html            页面结构：4 个标签页（今天 / 助手 / 进展 / 一根烟）、弹出面板、#about 项目介绍
css/style.css         样式：设计变量、深浅色模式
js/app.js             状态、记录、急救推荐、周报、演示数据、助手（工具 + 决策循环）
js/ai-config.js       线上 AI 转发地址（无密钥）
js/config.example.js  本机直连 AI 的配置示例
server/app.py         AI 转发云函数（Python 标准库），含 Agent 接口
server/test_app.py    Agent 消息校验测试：python3 -m unittest discover -s server
```

## 数据说明

- 每根烟约减少 11 分钟预期寿命：Shaw et al., *BMJ* 2000（人群统计估算）
- 恢复时间线：WHO、美国 CDC（人群平均趋势，不代表个人结果）
- 烟品焦油 / 烟碱 / CO：包装标示近似值，不同批次和市场有差异
- 演示数据为程序生成，不是真实用户数据
