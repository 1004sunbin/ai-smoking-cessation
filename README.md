# 每一根 · 戒烟陪伴

> 每一根都记下来，但一次复吸不让你从零开始。

一个移动端优先的戒烟陪伴 Web 应用，主打 **烟瘾急救** 和 **复吸后继续陪伴**。纯静态页面，无依赖、无后端，所有数据只保存在用户浏览器中。

## 运行

双击 `index.html` 用浏览器打开即可。首次打开会载入一份标注为「演示」的模拟数据，可直接体验，也可以选择「开始记录我自己的」。

项目介绍页（作品集）：在地址后加 `#about`，或在欢迎卡片 / 设置里点「关于这个项目」。

## 核心流程

| 流程 | 内容 |
| --- | --- |
| 设定目标 | 戒烟或减量；每天支数、每包价格作为基线。减量模式每周目标比基线降低 20% |
| 一键记录 | 「忍住了」一键记录；「抽了一根」记录场景；支持撤销、删除和补记更早的时间 |
| 烟瘾急救 | 选场景和渴求强度 → 推荐动作并计时 → 挺过去 / 还是抽了 → 评价方法是否有帮助 |
| 复吸之后 | 不评判；展示仍然有效的累计进度，针对诱因给出下一步 |
| 每周回顾 | 7 日趋势（基线 / 目标）、急救成功率、对你有效的方法、「下周试试这一件事」并追踪使用情况 |

急救推荐得分 = 场景匹配 + 强度匹配 + 个人效果（基于用户自己的评价），关闭个性化授权后只按场景和强度推荐。

## 隐私

- 记录、打卡、急救评价、对话只存在本机 localStorage，应用不发送任何网络请求
- 陪伴对话为本地规则；危机、急症、用药话题使用固定回复并给出求助渠道（12356 / 120 / 12320）
- 公开版不接入云端 AI：纯前端调用需要把 API 密钥放进浏览器，任何访客都能拿到。启动时会清除旧版本残留的密钥
- 设置中可一键清除全部数据；演示数据单独标注，可重置

## 数据说明

- 每根烟约减少 11 分钟预期寿命：Shaw et al., *BMJ* 2000（人群统计估算）
- 恢复时间线：WHO、美国 CDC（人群平均趋势，不代表个人结果）
- 烟品焦油 / 烟碱 / CO：包装标示近似值，不同批次和市场有差异
- 演示数据为程序生成，不是真实用户数据
