# 每一根 · 戒烟陪伴

> 每一根都记下来，但一次复吸不让你从零开始。

一个移动端优先的戒烟陪伴 Web 应用，主打 **烟瘾急救** 和 **复吸后继续陪伴**。纯静态页面，无依赖、无后端，所有数据只保存在用户浏览器中。

## 运行

双击 `index.html` 用浏览器打开即可。首次打开先设定目标（戒烟或减量、每天支数、价格），然后直接开始记录。想先看效果，可以在「设置 → 载入演示数据」载入一份标注为「演示」的模拟数据。

项目介绍页（作品集）：在地址后加 `#about`，或在欢迎卡片 / 设置里点「关于这个项目」。

## 核心流程

| 流程 | 内容 |
| --- | --- |
| 设定目标 | 戒烟或减量；每天支数、每包价格作为基线。减量模式每周目标比基线降低 20% |
| 一键记录 | 「忍住了」一键记录；「抽了一根」记录场景；支持撤销、删除和补记更早的时间 |
| 烟瘾急救 | 选场景和渴求强度 → 推荐动作并计时 → 挺过去 / 还是抽了 → 评价方法是否有帮助 |
| 复吸之后 | 不评判；展示仍然有效的累计进度，针对诱因给出下一步 |
| 每周回顾 | 7 日趋势（基线 / 目标）、急救成功率、对你有效的方法、「下周试试这一件事」并追踪使用情况 |

急救推荐得分 = 场景匹配 + 强度匹配 + 个人效果（基于用户自己的评价），关闭个性化授权后只按场景和强度推荐。

## 隐私

- 记录、打卡、急救评价只存在本机 localStorage，不上传
- 陪伴对话默认由 AI 回复（聊天框下方注明发送对象），可在设置里一键关闭、改用本地规则
- 危机、急症、用药话题始终在浏览器端用固定回复（12356 / 120 / 12320），不发给 AI
- 设置中可一键清除全部数据；演示数据单独标注，可重置

## AI 陪伴

```
浏览器 ──聊天内容 + 几项统计数字──▶ 阿里云函数（Key 在这里）──▶ 智谱 GLM 免费模型
```

- 线上：`js/ai-config.js` 里只写云函数地址，没有密钥；服务端代码和部署步骤见 [server/](server/)
- 云函数只接受本站调用，每位访客每天 20 条，系统提示词在服务端拼，不记录聊天内容
- 本机直连（可选）：复制 `js/config.example.js` 为 `js/config.local.js` 填 Key；该文件已被 `.gitignore` 忽略

## 目录

```
index.html            页面结构：4 个标签页、弹出面板、#about 项目介绍
css/style.css         样式：设计变量、深浅色模式
js/app.js             状态、记录、急救推荐、周报、演示数据、对话
js/ai-config.js       线上 AI 转发地址（无密钥）
js/config.example.js  本机直连 AI 的配置示例
server/app.py         AI 转发云函数（Python 标准库）
```

## 数据说明

- 每根烟约减少 11 分钟预期寿命：Shaw et al., *BMJ* 2000（人群统计估算）
- 恢复时间线：WHO、美国 CDC（人群平均趋势，不代表个人结果）
- 烟品焦油 / 烟碱 / CO：包装标示近似值，不同批次和市场有差异
- 演示数据为程序生成，不是真实用户数据
