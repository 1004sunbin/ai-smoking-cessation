    每一根 · 戒烟陪伴 Web 应用

    每一根都记下来，
    但一次复吸不让你从零开始。

    戒烟最难的是两个时刻：烟瘾冲上来的那几分钟，和抽了之后觉得"前功尽弃"的那一刻。这个项目围绕这两个时刻设计：烟瘾急救，以及复吸后继续陪伴。

    打开演示无需注册，内置模拟数据，可随时重置

    问题与目标

    观察到的问题

    • 多数戒烟 App 以"连续无烟天数"为核心，一次复吸就清零，用户容易就此放弃。
    • 烟瘾发作时，泛泛的建议（"坚持住"）帮不上忙，人需要一个马上能做的动作。
    • 不同的人、不同场景下有效的方法不一样，但很少有产品记录"什么对你有用"。

    产品目标

    • 帮用户撑过渴求高峰：按场景和强度给出一个具体动作。
    • 复吸后不清零：记录诱因、给出下一步，累计进度保持不变。
    • 每周给出一条可执行的建议，并追踪它有没有被用上。

    目标用户

    以下是设计时的用户假设，尚未经过用户访谈验证。

    想戒或想减量的成年吸烟者每天 10–20 根，尝试过戒烟但反复过；高频场景是饭后、工作压力和社交。
    核心需求烟瘾上来时有东西可以"抓住"；抽了之后不被责备；知道自己在哪些场景最容易失守。

    关键流程

    1. 设定目标选择"彻底戒烟"或"逐步减量"，填写每天支数和价格作为基线。减量模式每周目标比基线降低 20%。
    2. 一键记录"忍住了"一键记下，可撤销；"抽了一根"记录场景，可补记更早的时间。
    3. 烟瘾急救选场景和渴求强度 → 推荐一个动作并计时 → 结果（挺过去 / 还是抽了）→ 评价方法是否有效。
    4. 复吸后的下一步不评判；展示仍然有效的累计进度，并针对这次的诱因给出下次可以提前做的事。
    5. 每周回顾7 日趋势、与基线和目标对比、最有效的方法，以及"下周试试这一件事"。

    差异点：会学习的烟瘾急救

    急救方法库有 11 个动作（慢呼吸、冲动冲浪、离开现场、刷牙、拒绝句等），每个动作标注适合的场景和渴求强度。推荐分数由三部分组成：

    得分 = 场景匹配（通用 +1 / 匹配 +3）
     + 强度匹配（在区间内 +2 / 否则 −2）
     + 个人效果（有帮助 +2、一般 +0.5、没帮助 −1.5；挺过去 +0.5、抽了 −0.5；同场景记录 ×1.5）

    用户评价越多，推荐越偏向"对这个人在这个场景下有效"的方法。用户关闭个性化授权后，只按场景和强度推荐。

    隐私设计

    • 所有记录、打卡和急救评价只保存在用户浏览器的 localStorage 中，不上传。
    • 陪伴对话默认由 AI 生成，聊天框下方写明消息会发送给谁；在设置中可一键关闭，改用本地规则回复。只发送聊天内容和几项统计数字，不发送原始记录。
    • 涉及危机、急症和用药的话题始终在浏览器端使用固定回复，并给出 12356、120、12320 等求助渠道，不会发给 AI。
    • 设置中可以一键清除全部数据；演示数据单独标注，可随时重置或退出。
    一次取舍开发中曾尝试在前端直接接入云端大模型（Claude、硅基流动、Gemini）。纯静态页面调用这些服务必须把 API 密钥放在浏览器里，任何访客都能拿到，所以先撤掉了云端 AI。最终方案是加一个云函数转发：密钥只存在服务端；只接受本站调用；每位访客每天限 20 条；系统提示词在服务端拼，浏览器只能传聊天内容和几项统计数字，接口不能被拿去当通用聊天机器人；服务端不记录聊天内容。

    技术方案

    前端原生 HTML / CSS / JavaScript，无框架、无第三方依赖，托管在 GitHub Pages。
    AI 陪伴阿里云函数计算（Python 标准库）转发到智谱 GLM 免费模型，流式返回；主模型限流时自动切换备用模型，失败时退回本地规则回复。
    数据localStorage 单一状态对象；事件流（抽烟 / 忍住）带 id，支持撤销和补记；旧版数据自动迁移。
    统计口径"少抽的烟"= 基线 × 天数 − 实际记录，首页累计和周报共用同一个函数，避免数字互相对不上。
    界面移动端优先，深浅色模式，尊重"减少动态效果"系统设置。

    迭代记录

    1. v1 原型记录、恢复时间线、"一根烟"长按模拟：展示一根烟的焦油、尼古丁和一氧化碳。
    2. 烟品搜索每个人抽的烟不同，只有一个品牌时数字和用户无关。加入约 150 个国内外烟品规格的搜索，未收录的按常见标示估算并注明。
    3. 云端 AI 尝试与回退前端直连大模型有密钥暴露风险，先回退为本地规则（见隐私设计）。
    4. v2 重构把重心从"展示危害"转向"急救 + 复吸后陪伴"：急救按场景与强度推荐并收集效果反馈；复吸不清零累计进度；记录支持撤销和补记；修正减量目标和周报口径；加入演示模式。
    5. AI 陪伴上线加入云函数转发、限流和安全话题本地拦截。最初需要访客点击同意才开启，试用中觉得多了一步阻碍，改为默认开启、在聊天框下方说明并可在设置中关闭；测试中发现"胸口有点痛"这类说法没被识别为急症，扩充了识别规则，并在 AI 提示词里加了第二道保险。

    数据说明与局限

    • 每根烟约减少 11 分钟预期寿命来自人群统计（Shaw 等，BMJ 2000）；恢复时间线参考 WHO 和美国 CDC。应用内的寿命、恢复和焦油数字都是估算，不代表个人医学结果。
    • 烟品焦油、烟碱、一氧化碳为包装标示的近似值，不同批次和市场会有差异。
    • 目前没有真实用户数据，演示数据为程序生成。下一步计划邀请 5 位吸烟者做可用性测试，关注三个指标：急救流程的完成率、急救后"挺过去"的比例、复吸后 7 天内是否继续记录。
    本应用提供行为支持与健康科普，不提供诊断或用药建议。中国戒烟咨询可拨打 12320 卫生热线。
