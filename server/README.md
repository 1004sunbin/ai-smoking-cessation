# AI 助手转发服务

浏览器 → 本服务（API Key 只存在服务端环境变量里）→ 智谱 GLM 免费模型。

只用 Python 标准库，没有依赖，部署为云函数的「Web 函数」即可（监听 9000 端口）。

## 它做了什么

- 只接受来自 `ALLOWED_ORIGINS` 的网页调用，其他网站一律拒绝
- 每个访客每天最多 `PER_IP_DAILY` 条（默认 20），全站每天最多 `DAILY_CAP` 条（默认 500）；超了返回 429，前端自动改用本地回复
- 系统提示词在服务端拼，浏览器只能传聊天内容（每条最多 300 字、最近 10 条）和几项统计数字，接口不能被拿去当通用聊天机器人
- 先用 `glm-4.7-flash`，免费模型高峰期限流或超时时自动换 `glm-4-flash-250414`
- 不记录聊天内容，没有数据库

## Agent 接口

请求带 `"agent": true` 时走 Agent 模式：服务端加上固定的系统提示词和 7 个工具定义，非流式调用一次模型，返回 `{message, model}`。`message` 可能是最终文字，也可能是 `tool_calls`。工具由浏览器在本机执行，再把结果作为 `role: "tool"` 消息发回来，继续下一轮。

- 只接受已定义的工具名；`tool` 消息必须对应前面的 `tool_calls`，结构对不上整体拒绝；不接受 `system` 消息
- 一条用户消息最多 4 轮工具调用
- 只有用户新发消息才扣额度，同一条消息里的工具往返不重复计数

测试：`python3 -m unittest discover -s server -v`

计数保存在内存里，实例重启后清零，对演示足够。

## 部署到阿里云函数计算（FC 3.0）

1. 打开 [函数计算控制台](https://fcnext.console.aliyun.com)，开通服务（需要实名认证）
2. 「函数」→「创建函数」→ 选 **Web 函数**
3. 基本设置：
   - 函数名称：`meiyigen-ai`
   - 运行环境：**Python 3.10**
   - 代码：选「使用示例代码」，创建后在在线编辑器里把示例代码换成本目录的 `app.py`（文件名也叫 `app.py`），点「部署代码」
   - 启动命令：`python3 app.py`，监听端口：`9000`
4. 高级配置：地域选离你近的（如华东 1 杭州），执行超时时间改为 `60` 秒，规格保持最小即可
5. 环境变量：添加 `ZHIPU_API_KEY` = 你的智谱 API Key
6. 触发器：HTTP 触发器，认证方式 **无需认证**，请求方法勾选 `GET`、`POST`、`OPTIONS`
7. 创建完成后，在「触发器管理」里复制 **公网访问地址**

## 接入前端

把公网访问地址填到 `js/ai-config.js` 的 `url`，提交推送后，线上网站的「助手」就会由 AI 驱动。**修改 `app.py` 后需要在控制台重新粘贴部署**，否则线上助手会自动退回本地规则。

## 本地运行

```bash
ZHIPU_API_KEY=你的Key python3 app.py
```

macOS 上如果报 `CERTIFICATE_VERIFY_FAILED`，在命令前加 `SSL_CERT_FILE=/etc/ssl/cert.pem`。
